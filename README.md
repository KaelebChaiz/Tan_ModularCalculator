# Modular Calculator


## Suggested Program Flow

Your calculator may follow this flow:

1. Start
2. Ask the user to enter the first number
3. Ask the user to enter the second number
4. Ask the user to choose an operation
5. Call the correct function based on the selected operation
6. Store the returned value in a variable
7. Display the result
8. End

## Programming Task


### A. Input

Your program should ask the user for:

First number
Second number
Operation to perform

Example operation choices:
1 - Addition
2 - Subtraction
3 - Multiplication
4 - Division

### B. Process

Your program should:

- Pass the two numbers as arguments to the correct function
- Use the function parameters to receive the values
- Process the values inside the function body
- Return the result to the caller

### C. Output

Your program should display the result clearly.

Example:

Enter first number: 10
Enter second number: 5

Choose operation:
1 - Addition
2 - Subtraction
3 - Multiplication
4 - Division

Enter choice: 1

Result: 15
